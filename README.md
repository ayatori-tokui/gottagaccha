# 🎀 Gotta!Gaccha!

店頭でくじ（一番くじ、トレカのオリパなど）を引くときに、スマホで素早く **期待値・還元率・当たる確率** を計算し、**実践結果の損益** を記録・バックアップできる Web アプリです。

- ビルド不要（HTML + Vanilla JS + Tailwind CSS CDN）
- GitHub Pages でそのまま公開可能
- データはすべてブラウザの Local Storage に保存（サーバー送信なし）

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | マークアップ、Tailwind CSS（CDN）の読み込み |
| `script.js` | 計算ロジック、Local Storage、JSON/CSV 入出力、DOM 操作、履歴管理（編集・メモ） |
| `sw.js` | Service Worker（オフライン対応、Stale-while-revalidate） |
| `manifest.webmanifest` / `icons/` | PWA 設定とアイコン |

## 使い方

1. **シミュレーション**タブで、1回の金額・残り総本数・ラストワン賞の価値、当たり枠（名前・価値・残り本数）、引く回数 n を入力。結果は入力のたびに更新されます。
2. **実践履歴・設定**タブで、引いた回数と当たった賞品の合計価値を入力して記録。使った金額は `回数 × 1回の金額` で自動計算されます。
3. 記録にはメモ（店名・くじ名など）を付けられ、履歴の ✏️ から回数・金額・価値・メモを後から編集できます。
4. 損益がプラスは赤字、マイナスは青字で表示されます。
5. バックアップ（JSON）、CSV 出力、JSON 復元（マージ / 上書き）が可能です。

## 計算ロジック

記号の定義：

| 記号 | 意味 |
| --- | --- |
| $P$ | 1回あたりの金額 |
| $N$ | 現在の残り総本数 |
| $L$ | ラストワン賞の価値 |
| $b$ | 外れくじ1本の価値（初期値 0。当たり枠に登録しない残り全部が外れ） |
| $B = \max(0,\ N-K)$ | 外れくじの本数 |
| $n$ | 引く回数（$n > N$ の場合は $n = N$ として扱う） |
| $k_i,\ v_i$ | 当たり枠 $i$ の残り本数・価値 |
| $K = \sum k_i$ | 当たり枠の合計本数 |

### 期待値・還元率

$$E = \frac{\sum_i v_i k_i + b\,B}{N}\qquad \text{還元率} = \frac{E}{P}\times 100\ (\%)$$

ラストワン賞は「最後の1本を引いた人だけ」が得るため、1回あたりの期待値には含めません。

### n回引く場合

$$\text{合計コスト} = P\,n\qquad \text{損益の期待値} = E\,n - P\,n$$

### 全買い（残り全部を引き切る）

$$\text{総コスト} = P\,N\qquad \text{最終損益} = \sum_i v_i k_i + b\,B + L - P\,N$$

### 当たる確率（非復元抽出・超幾何分布）

$N$ 本中に対象の当たりが $K$ 本あるとき、$n$ 回引いて **1本も当たらない確率** は

$$P_{\text{miss}} = \frac{\binom{N-K}{n}}{\binom{N}{n}} = \prod_{j=0}^{n-1}\frac{N-K-j}{N-j}$$

階乗や二項係数を直接計算するとオーバーフローするため、右辺の **積をループで計算** します（各項は 0〜1 なので安定）。「少なくとも1本当たる確率」は余事象として求めます。

$$P_{\text{hit}} = 1 - P_{\text{miss}}$$

- **全体の当たる確率**：$K = \sum k_i$（登録した全当たり枠の合計）として計算。
- **個別の当たり枠の確率**：当たり枠 $i$ について $K = k_i$ とし、それ以外はすべてハズレとみなして計算。

境界条件：

- $K = 0$ のとき $P_{\text{miss}} = 1$（当たる確率 0%）
- $n > N - K$ のとき $P_{\text{miss}} = 0$（確実に当たる）

実装は `script.js` の `missProb(N, K, n)` / `atLeastOne(N, K, n)` を参照してください。

#### 例

80本中1本の当たりを10回引く：$1-\prod_{j=0}^{9}\frac{79-j}{80-j} = 1-\frac{70}{80} = 12.5\%$

## データの保存・バックアップ

| 機能 | 内容 |
| --- | --- |
| 自動保存 | 入力内容は `kuji_state_v1`、履歴は `kuji_history_v1` に Local Storage 保存し、リロード時に復元 |
| JSON エクスポート | `kuji_history.json`（`{ version, exportedAt, history[] }`） |
| JSON インポート | マージ（`id` が重複するものは無視）または上書き |
| CSV 出力 | 列：日時, 回数, 使った金額, 得た価値, 損益金額, メモ。Excel での文字化け防止のため UTF-8 BOM 付き |

履歴には、記録時点のシミュレーション条件（`cond`：1回の金額・残り本数・外れ価値・ラストワン価値・当たり枠一覧・1回の期待値・還元率）も一緒に保存されます。履歴画面の「記録時の条件」から確認でき、CSV にも列として出力されます（旧バージョンの履歴は `cond` なしで読み込めます）。

履歴 1 件のデータ形式：

```json
{ "id": "lx3k9a2b", "date": "2026-11-10T14:00:00.000Z", "count": 10, "cost": 8000, "value": 3000, "profit": -5000, "memo": "○○店",
  "cond": { "price": 800, "total": 80, "lastOne": 0, "blank": 0, "n": 10,
            "prizes": [{ "name": "A賞", "value": 5000, "count": 1 }], "ev": 62.5, "rate": 7.81 } }
```

## PWA / オフライン

HTTPS（GitHub Pages）で開くと Service Worker が登録され、ホーム画面に追加してアプリとして使えます。初回オンライン表示で全ファイル（Tailwind CDN を含む）をキャッシュし、以降は電波のない店内でも動作します。ファイルを更新したら `sw.js` の `CACHE` 名を変更してください。

## GitHub Pages で公開する

1. `index.html`・`script.js`・`sw.js`・`manifest.webmanifest`・`icons/`・`README.md` をリポジトリのルートに置く
2. Settings → Pages → Branch を `main` / `(root)` に設定して保存

## 注意

- 本アプリの数値は入力値に基づく計算結果であり、当選を保証するものではありません。
- Local Storage はブラウザのデータ削除で消えます。定期的にバックアップを保存してください。
